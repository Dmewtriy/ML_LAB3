# Лабораторная работа 3 Кластеризация

Сравнение K-means и иерархической кластеризации методом Уорда на пяти признаках синтетических игр Steam.

## Состав проекта

- `dataset/` — исходный CSV и описание набора.
- `src/clustering.py` — анализ данных, кластеризация, метрики и построение графиков.
- `docs/` — отчёт Word с полным листингом.
- `screenshots/` — восемь графиков, включая матрицу корреляций Спирмена.
- `requirements.txt` — зависимости Python.

## Запуск

Из корня `lab_3` в PowerShell. Расчёты проверены с Python 3.12.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src\clustering.py
```

На этом компьютере можно запустить скрипт через окружение ЛР4, где эти библиотеки уже установлены:

```powershell
& 'C:\unik\ML\lab4\.venv\Scripts\python.exe' src\clustering.py
```

Метрики, размеры групп и их центры выводятся в консоль. Графики сохраняются в `screenshots/`.

## Что объяснить на защите

1. Пять признаков описывают масштаб проекта, цену, оценку критиков и интерес игроков. `hit` нужен только для внешней оценки готового разбиения.
2. `log1p` уменьшает правую асимметрию трёх признаков. По ящикам с усами видно, как изменились хвосты распределений. `StandardScaler` приводит признаки к сопоставимому масштабу перед расчётом расстояний.
3. K-means уточняет центры групп, а метод Уорда последовательно объединяет группы с наименьшим приростом суммы квадратов. Для обоих методов средний силуэт максимален при `k=2`.
4. В первой группе более 99 % инди-игр, во второй — менее 1 %. Метка `is_indie` служит для интерпретации групп. ARI между методами равен 0,9895, а ARI с `hit` составляет около 0,07.
