## 8. Покажите, как выявляются выбросы. Как в коде реализовано принятое решение об их обработке?

`outliers()` (97–101) вычисляет Q1, Q3 и IQR = Q3 − Q1. Значения вне [Q1 − a·IQR, Q3 + a·IQR] отмечаются булевой маской. На ящиках с усами (79–94, `07-boxplots.png`) используется 1,5 IQR. Например, после `log1p` у объёма игры число точек за усами снизилось с 610 до 0.

В строках 175–184 решение о фильтрации принимается по более строгому порогу 3 IQR на преобразованных данных. `keep = ~outliers(transformed, 3).any(axis=1)` оставляет строки без таких значений. Сохранились все 8 000 игр.

`clustering.py`, строки 97–101

```python
def outliers(data, factor):
    q1 = data.quantile(0.25)
    q3 = data.quantile(0.75)
    iqr = q3 - q1
    return (data < q1 - factor * iqr) | (data > q3 + factor * iqr)
```

`clustering.py`, строки 177–184

```python
    "1.5 IQR до": outliers(data[FEATURES], 1.5).sum(),
    "1.5 IQR после": outliers(transformed, 1.5).sum(),
    "3 IQR после": outliers(transformed, 3).sum(),
}))
keep = ~outliers(transformed, 3).any(axis=1)
games = data.loc[keep].reset_index(drop=True)
x = StandardScaler().fit_transform(transformed.loc[keep])
print(f"Оставлено: {len(games)}, исключено: {(~keep).sum()}")
```

## 19. Если используется DBSCAN, покажите, где задаются eps, min_samples и метрика расстояния. В каком пространстве признаков применяется eps?

В этой лабораторной используются K-means и Уорд. В DBSCAN `eps` задаёт радиус соседства, а `min_samples` — минимум точек в нём, включая сам объект, для статуса ядра. `metric` задаёт расстояние. Если DBSCAN обучить на `x` с `metric="euclidean"`, `eps` измеряется в пятимерном пространстве стандартизованных признаков.

**Учебный фрагмент. В скрипте ЛР3 его нет.**

```python
from sklearn.cluster import DBSCAN

# Учебные параметры, не результат подбора.
model = DBSCAN(eps=0.5, min_samples=5, metric="euclidean")
labels = model.fit_predict(x)
```

## 29. Где вычисляются внутрикластерные расстояния и компактность? Как именно определены эти показатели в вашей программе?

Строки 132–140. Средний радиус — среднее евклидово расстояние до собственного центра, `np.linalg.norm(points - center, axis=1).mean()`. Среднее попарное расстояние — `pdist(points).mean()`, каждая пара различных игр учитывается один раз. У K-means средние радиусы 1,370 и 1,703, а попарные расстояния 1,934 и 2,394. У второй группы больший разброс.

`clustering.py`, строки 132–140

```python
centers = []
for group in profiles.index:
    points = x[labels == group]
    center = points.mean(axis=0)
    centers.append(center)
    radius = np.linalg.norm(points - center, axis=1).mean()
    pair_distance = pdist(points).mean()
    print(f"Группа {group}: средний радиус {radius:.3f}, "
          f"среднее попарное расстояние {pair_distance:.3f}")
```
