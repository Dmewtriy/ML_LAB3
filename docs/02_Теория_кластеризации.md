# Теория кластеризации

Лабораторная работа 3 «Кластеризация»

Краткие ответы на теоретические вопросы с обозначениями и формулами метрик.

## 1. Задача кластеризации. Отличия кластеризации от классификации.

Кластеризация ищет группы похожих объектов по их признакам. При обучении без учителя алгоритм получает X и строит разбиение. Классификация учится по парам X и y, где названия классов известны. Её цель — присваивать известные классы новым объектам.

В лабораторной группы строятся по свойствам игр. Имеющуюся метку коммерческого успеха hit используют после обучения, чтобы проверить, насколько она согласуется с группами.

## 2. Условия применения кластеризации.

Нужно определить, что означает сходство объектов и зачем нужны группы. Признаки, расстояние и метод должны отражать эту цель. Проверяют пропуски, ошибки, дубликаты, выбросы и разброс масштабов. В постановке без учителя метки классов исключают из входной матрицы. Если они известны, их можно оставить для внешней проверки.

Группы могут быть слабо выражены. Применимость разбиения проверяют по визуализациям, метрикам, устойчивости и содержательному смыслу. Универсального требования нормальности признаков или полного отсутствия выбросов нет. Чувствительность зависит от метода.

## 3. Подготовка данных к кластеризации. Масштабирование признаков, обработка пропусков и выбросов.

Сначала анализируют типы данных и удаляют служебные идентификаторы. При пропусках выбирают заполнение или удаление с учётом количества и природы пропусков. Например, числовые пропуски можно заполнить медианой, а неизвестную категорию выделить отдельно.

Выбросы проверяют по контексту и графикам. Ошибки исправляют или исключают, правдоподобные редкие значения можно сохранить. Логарифм `log1p(x)` сжимает правый хвост неотрицательных величин. При стандартизации z = (x − μ) / σ, при Min-Max масштабировании x′ = (x − min) / (max − min). StandardScaler удобен для евклидовых методов, RobustScaler опирается на медиану и межквартильный размах.

## 4. Основные виды методов кластеризации.

Центроидные методы, например K-means, строят компактные группы вокруг центров. Иерархические методы строят дерево вложенных групп, например методом Уорда. Плотностные методы, например DBSCAN, находят связанные области высокой плотности. Модели смесей, например гауссовская смесь, описывают данные как смесь вероятностных компонент. Число кластеров, геометрия групп и роль шума определяют выбор.

## 5. Визуальная оценка кластерной структуры и выбор метода. Возможности и ограничения диаграмм рассеивания.

На диаграмме рассеивания оценивают число облаков, вытянутость, перекрытие, относительный разброс, плотность и изолированные точки. Компактные облака поддерживают выбор K-means или Уорда, эллипсы с разной ориентацией — гауссовской смеси, группы сложной формы с шумом — DBSCAN при подходящей плотности.

Двумерная проекция теряет часть измерений. Группы, пересёкшиеся на плоскости, могут отличаться по другим признакам. Рисунок помогает сформулировать гипотезу, которую проверяют метриками в пространстве обучения и устойчивостью разбиения.

## 6. Меры расстояния между объектами. Влияние выбора расстояния на результат кластеризации.

Расстояние определяет ближайший центр, соседа или порядок слияния. Евклидово расстояние естественно для сопоставимых числовых признаков. Манхэттенское суммирует абсолютные различия, косинусное сравнивает направление векторов, Хэмминга — несовпадения категориальных или двоичных значений. Для смешанных признаков применяют, например, расстояние Гауэра.

Смена расстояния или масштаба может перестроить группы. K-means с арифметическим средним минимизирует сумму квадратов евклидовых расстояний. Уорд в стандартной постановке также требует евклидовой геометрии.

## 7. Метод K-средних. Основные этапы алгоритма.

1) Задать k начальных центров. K-means++ выбирает их разнесёнными с большей вероятностью. 2) Назначить каждой точке ближайший центр. 3) Заменить каждый центр средним координат его группы. 4) Повторять шаги 2–3 до сходимости или лимита итераций.

Инерция равна Σᵢ ‖xᵢ − μ[labelᵢ]‖². Чем она меньше при фиксированном k, тем компактнее группы в этой геометрии. Возможны локальные минимумы, поэтому делают несколько инициализаций и выбирают запуск с минимальной инерцией.

## 8. Метод локтя. Метод силуэта.

Метод локтя строит инерцию по k. Ищут изгиб, после которого добавление центров даёт гораздо меньший выигрыш. Минимум инерции по всему диапазону указывает на большое k, поэтому сам по себе не помогает выбрать число групп.

Метод силуэта для каждого объекта сравнивает среднее расстояние a до своего кластера и минимальное среднее b до другого. s = (b − a) / max(a, b). Для набора считают среднее s и ищут высокий показатель. Если методы предлагают разные k, проверяют структуру групп, их размеры и устойчивость.

## 9. Иерархическая кластеризация. Принцип работы агломеративного алгоритма.

Агломеративный алгоритм начинает с n групп из одного объекта. На каждой итерации выбирает пару групп для слияния по выбранному критерию, объединяет её и пересчитывает расстояния до новой группы. После n − 1 слияний остаётся одна группа. Срез дерева на нужном уровне даёт плоское разбиение.

## 10. Методы определения расстояния между кластерами в иерархической кластеризации.

Single linkage — минимальное расстояние между точками разных групп, может образовывать цепочки. Complete linkage — максимальное, обычно даёт более компактные группы. Average linkage — среднее всех межгрупповых попарных расстояний.

Метод Уорда объединяет группы с наименьшим приростом внутрикластерной суммы квадратов. Для групп A и B прирост равен |A|·|B| / (|A| + |B|) × ‖μA − μB‖². Поэтому учитываются и расстояние между центрами, и размеры групп.

## 11. Дендрограмма. Построение, интерпретация и выбор итогового разбиения.

Листья дендрограммы соответствуют объектам или свёрнутым ветвям. Каждая горизонтальная перемычка обозначает слияние, высота показывает его значение по критерию связывания. Порядок листьев по горизонтали может меняться при перестановке дочерних ветвей.

Если есть заметный скачок высоты, горизонтальный срез ставят ниже скачка. Число пересечённых ветвей равно числу групп. Срез сравнивают с силуэтом и проверяют содержательность групп.

## 12. Алгоритм DBSCAN.

DBSCAN выделяет области высокой плотности. Если в радиусе ε вокруг точки есть как минимум min_samples объектов, включая её саму, она считается ядром. Связанные соседством ядра образуют группы. Точки рядом с ядрами могут быть граничными, остальные получают метку шума.

Заранее задавать k не требуется. Метод находит группы произвольной формы, но один ε может плохо подходить для областей с очень разной плотностью. Выбор масштаба и метрики влияет на состав соседства.

## 13. Модель смеси гауссовских распределений.

Гауссовская смесь представляет плотность как p(x) = Σⱼ πⱼ N(x | μⱼ, Σⱼ). Для каждой из k компонент оцениваются вес πⱼ, вектор среднего μⱼ и ковариация Σⱼ. Веса неотрицательны и суммируются к 1. Ковариация задаёт разброс и ориентацию эллипсоида компоненты.

Готовая модель выдаёт вероятности принадлежности. Жёсткая метка получается выбором самой вероятной компоненты. Число компонент можно сравнивать, например, по BIC с учётом сложности.

## 14. EM-алгоритм для гауссовской смеси.

После инициализации повторяются два шага. На E-шаге для каждой пары «объект — компонента» вычисляют ответственность rᵢⱼ. Это взвешенная плотность компоненты в точке, делённая на суммарную взвешенную плотность. Для объекта Σⱼ rᵢⱼ = 1.

На M-шаге веса, средние и ковариации пересчитывают по ответственностям. Если Nⱼ = Σᵢ rᵢⱼ, то πⱼ = Nⱼ / n, μⱼ = Σᵢ rᵢⱼ xᵢ / Nⱼ, а ковариация — взвешенное среднее внешних произведений отклонений от μⱼ. Цикл завершается при малом изменении критерия или достижении лимита итераций. Инициализация влияет на решение.

## 15. Самоорганизующаяся карта Кохонена.

Карта Кохонена SOM — сетка узлов, у каждого есть вектор-прототип в исходном пространстве признаков. Для объекта находят ближайший узел, победителя BMU. Прототип победителя и его соседи по сетке немного сдвигаются к объекту, причём влияние уменьшается с расстоянием по сетке. Скорость обучения и радиус соседства обычно уменьшаются со временем.

В результате близким объектам обычно соответствуют близкие узлы. Карта даёт визуальное представление структуры, а выделение кластеров может потребовать отдельного шага.

## 16. Меры расстояния между точками.

Евклидово расстояние L₂ равно √(Σⱼ (xⱼ − yⱼ)²). Манхэттенское L₁ равно Σⱼ |xⱼ − yⱼ|. Расстояние Чебышёва L∞ равно maxⱼ |xⱼ − yⱼ|. Расстояние Минковского Lₚ равно (Σⱼ |xⱼ − yⱼ|ᵖ)^(1/p) при p ≥ 1.

Косинусное различие для ненулевых векторов равно 1 − (x·y)/(‖x‖·‖y‖). Хэмминг — число или доля несовпадающих позиций в зависимости от принятой нормировки.

## 17. Внутренние метрики качества кластеризации. Формулы и интерпретация.

Внутренние метрики используют X и полученные метки. Они оценивают геометрию разбиения.

В формуле силуэта s = (b − a) / max(a, b) величина a — среднее расстояние до остальных точек своей группы, b — наименьшее среднее расстояние до любой другой группы. Среднее ближе к 1 означает лучшее отделение. Около 0 — граница или перекрытие, отрицательное значение — точка в среднем ближе к другой группе.

Индекс Calinski–Harabasz равен CH = [B / (k − 1)] / [W / (n − k)]. W — сумма квадратов расстояний точек до собственных центров, B — сумма квадратов расстояний центров до общего среднего с весами по численности групп. Больше — выше разделённость относительно разброса.

Индекс Davies–Bouldin равен DB = (1/k) Σᵢ maxⱼ≠ᵢ [(Sᵢ + Sⱼ) / d(μᵢ, μⱼ)]. Sᵢ — среднее расстояние точек до центра группы i. Чем меньше индекс, тем компактнее группы относительно расстояний между их центрами.

## 18. Внешние метрики качества кластеризации. Формулы и интерпретация.

Внешние метрики сравнивают кластеры с эталонной разметкой одних и тех же объектов. Пусть a — пары в одной группе обеих разметок, d — пары в разных группах в обеих, b и c — два вида несогласия. Rand = (a + d) / (a + b + c + d). Парный Жаккар J = a / (a + b + c). Высокий Rand может возникнуть из-за большого числа пар типа d.

Для ARI из матрицы сопряжённости берут S = Σᵢⱼ C(nᵢⱼ, 2), R = Σᵢ C(nᵢ·, 2), C = Σⱼ C(n·ⱼ, 2), M = C(n, 2), где C(m, 2) = m(m − 1)/2. Тогда ARI = [S − RC/M] / [(R + C)/2 − RC/M]. Значение 1 означает совпадение вплоть до номеров, около 0 — уровень случайного согласия при фиксированных размерах групп, отрицательное — ниже этого уровня.
